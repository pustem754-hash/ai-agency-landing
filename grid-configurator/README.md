# GRID — 3D-конфигуратор модульного стеллажа

Прототип карточки товара для интернет-магазина: покупатель вращает модель,
собирает конфигурацию и сразу видит габариты и цену.

Стек: Vite + React + TypeScript, Three.js через React Three Fiber и Drei,
состояние — Zustand. Геометрия строится процедурно из примитивов, внешних
моделей, платных ассетов и сетевых запросов нет — работает без интернета.

## Запуск

```bash
npm install
npm run dev      # дев-сервер
npm run build    # tsc -b + vite build
npm run preview  # предпросмотр собранного билда
```

## Конфигурация и цена

| Параметр | Варианты | Цена |
|---|---|---|
| Секции по ширине | 2 / 3 / 4 | база 12 900 ₽, каждая следующая +4 200 ₽ |
| Ярусы по высоте | 3 / 4 / 5 | каждый следующий +3 100 ₽ |
| Материал корпуса | ЛДСП дуб / ЛДСП белый / металл чёрный | металл +8 000 ₽ |
| Форма корпуса | прямой / мягкий R12 / округлый R30 | +0 / +2 900 ₽ / +5 400 ₽ |
| Толщина полок | 16 / 22 / 36 мм | +0 / +1 800 ₽ / +4 600 ₽ |
| Задняя стенка | нет / ХДФ / зеркало | +0 / +2 400 ₽ / +6 900 ₽ |
| Ящики | 0 / 1 / 2 | каждый +3 800 ₽ |

Артикул собирается из выбранного: `GRID-3S-4Y-MTL-HDF-2D-T22-R12`.

## Габариты

Считаются из параметров, а не берутся из таблицы (`calcDimensions`):

```
ширина  = секции × 40 см + (секции + 1) × толщина_плиты
высота  = ярусы × 36 см + (ярусы + 1) × толщина_плиты + 4 см (ножки)
глубина = 32 см + 0,6 см, если задняя стенка накладная
```

## Функции

- вращение мышью, зум с ограничением по дистанции, кнопка «Вернуть обзор»;
- кадр подстраивается под габариты: при смене конфигурации камера отъезжает,
  чтобы модель целиком влезала;
- три точки-подсказки на модели (кружок с номером) и те же три чипа в панели —
  клик подлетает камерой и открывает карточку узла в левом нижнем углу сцены;
- режим разборки: крышка и полки расходятся по вертикали равными интервалами,
  стойки — в стороны, задняя стенка назад, ящики вперёд, ножки вниз;
- «Сохранить PNG» — снимок текущего кадра, имя файла из конфигурации
  (`grid-2s-5y-white-2d.png`).

## Технические решения, важные для работы

- `gl={{ preserveDrawingBuffer: true }}` — без этого браузер очищает буфер
  после композитинга и снимок приходит пустым.
- Снимок отдаётся через `canvas.toBlob` и `blob:`-ссылку: Chrome игнорирует
  атрибут `download` у длинных `data:`-URL и сохраняет файл без имени.
- Окружение для отражений генерируется процедурно (`Environment` + `Lightformer`),
  HDR-карты не скачиваются. Для зеркальной стенки этого мало, поэтому она
  рисуется `MeshReflectorMaterial` — настоящим отражением сцены.
- Радиус скругления зажимается половиной меньшей стороны детали: на плите
  16 мм радиус 30 мм физически невозможен, геометрия схлопнулась бы.
- Селекторы Zustand возвращают только примитивы. Селектор, собирающий новый
  объект, в zustand v5 (`useSyncExternalStore`) даёт бесконечный ре-рендер.

## Автопроверка геометрии

В `window` выведены `__gridStore` (стор) и `__gridScene` (сцена) — по ним
скриптом проверяется, что детали не пересекаются. Проверка гоняет 81 комбинацию
(секции × ярусы × толщина × форма) и сравнивает мировые AABB деталей с метками
`panel` / `shelf` / `back` / `drawer`.

Так был найден и исправлен реальный дефект: задняя стенка стояла внутри корпуса
и пересекала боковины и полки на 6 мм по глубине.
